# RescueOps - Coordination intelligente des urgences

Projet AWD (Architecture Web Distribuée) : 7 microservices Spring Boot, une API Gateway, Eureka, Keycloak, MySQL, RabbitMQ et un frontend Angular.

> Ce README est complété à la fin du plan 1 (lancement du socle en une commande).

## Prérequis
- Java 21 (Temurin)
- Docker Desktop
- Node.js 22 (pour le frontend)
- Maven n'est **pas** nécessaire : utiliser `./mvnw` (Linux/macOS/Git Bash) ou `mvnw.cmd` (Windows).
