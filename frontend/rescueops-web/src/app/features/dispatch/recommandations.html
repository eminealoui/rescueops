Algorithme de Dispatching Intelligent

Le calcul applique une pondération multicritère pour optimiser le temps de réponse opérationnel :

  • Proximité géographique (60%) : Calcul de distance réelle à vol d'oiseau (formule de Haversine).
  • Disponibilité immédiate (30%) : Bonus accordé aux unités prêtes au déploiement immédiat.
  • Adéquation compétence (10%) : Conformité exacte avec le type d'intervention demandé.
Score = (Distance_norm × 0.60) + (Disponibilité × 0.30) + (Compétence × 0.10)
